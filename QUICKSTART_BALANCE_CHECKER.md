# Quick Start: View All Rainbow Wallet Balances on iPhone

This guide will help you quickly set up and use the Rainbow Wallet Balance Checker shortcut.

## 📱 3-Minute Setup

### Step 1: Get the Shortcut (30 seconds)
1. On your iPhone, download `RainbowWalletBalanceChecker.shortcut` from this repo
2. Tap the downloaded file
3. Tap "Add Shortcut"

### Step 2: Run It (10 seconds)
1. Open the **Shortcuts** app
2. Find and tap **"Rainbow Wallet Balance Checker"**

### Step 3: View Your Balances (1 minute)
1. Rainbow wallet will open automatically
2. **Pull down** to refresh balances
3. Follow the on-screen prompts

## 🎯 One-Tap Access (Optional)

### Add to Home Screen
1. In Shortcuts app, find the shortcut
2. Tap the **⋯** (three dots)
3. Tap **"Add to Home Screen"**
4. Now launch with one tap!

## 🔍 If Balances Are Still Hidden

### Quick Fix #1: Unhide Tokens
```
1. When prompted, type: settings
2. Go to: Wallets → [Your Wallet] → Hidden Tokens  
3. Tap to unhide any tokens
```

### Quick Fix #2: Enable Small Balances
```
1. Open Rainbow Settings
2. Enable "Show small balances"
3. Pull down to refresh
```

### Quick Fix #3: Check Network
```
1. Ensure internet connection is active
2. Try switching Wi-Fi/cellular
3. Pull down to refresh again
```
